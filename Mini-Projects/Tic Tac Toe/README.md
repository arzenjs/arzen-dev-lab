# Tic Tac Toe

An interactive Tic Tac Toe game built with Next.js and React. The application provides a browser-based implementation of the classic two-player game.

## Live Demo

[Play Tic Tac Toe](https://tictactoe-nine-flax.vercel.app/)

## Tech Stack

- Next.js 14
- React 18
- JavaScript
- Tailwind CSS 3
- Framer Motion
- Lucide React
- next-themes

## Getting Started

Clone the repository:

```bash
git clone https://github.com/arzenjs/arzen-dev-lab.git
```

Navigate to the project directory:

```bash
cd "arzen-dev-lab/Mini-Projects/Tic Tac Toe"
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production Build

```bash
npm run build
```
