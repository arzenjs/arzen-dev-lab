# iTasks — React To-Do App

## Overview
iTasks is a **To-Do app built with React**.  
You can **add, edit, delete, mark tasks as completed**, and filter tasks (All / Pending / Completed).  
All tasks are **saved in local storage**, so they stay after closing the browser.

---

## How to Run
1. Install **Node.js and npm**: [https://nodejs.org/](https://nodejs.org/)
2. Open terminal in the project folder.
3. Run:
   npm install & 
   npm run dev
4. The app opens in your browser automatically (usually http://localhost:5173/).
