# Google Clone

A frontend recreation of the Google homepage, built using HTML, CSS, and vanilla JavaScript. The project recreates the familiar search interface while allowing users to perform searches through Google's actual search results.

## Live Demo

[Open Google Clone](https://google-beta-one.vercel.app/)

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Features

- Google-inspired homepage interface
- Search input with Google search redirection
- Search button
- I'm Feeling Lucky button
- Navigation links
- Responsive layout

## Getting Started

Clone the repository:

```bash
git clone https://github.com/arzenjs/arzen-dev-lab.git
```

Navigate to the project directory:

```bash
cd arzen-dev-lab/Mini-Projects/Google
```

Open `index.html` in your browser.

No package installation or development server is required.
