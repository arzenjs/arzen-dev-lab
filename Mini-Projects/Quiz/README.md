# Quiz

An interactive quiz application built with Next.js and React. The project provides a user interface for answering quiz questions and viewing results.

## Live Demo

[Open Quiz](https://quiz-nu-pied-96.vercel.app/)

## Tech Stack

- Next.js 14
- React 18
- JavaScript
- Tailwind CSS 3
- Framer Motion
- Lucide React
- next-themes

## Getting Started

Clone the repository:

```bash
git clone https://github.com/arzenjs/arzen-dev-lab.git
```

Navigate to the project directory:

```bash
cd arzen-dev-lab/Mini-Projects/Quiz
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production Build

```bash
npm run build
```
