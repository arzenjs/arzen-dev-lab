# Arzen Dev Lab

A collection of web development projects, experiments, and interactive applications built by **Mohammad Arsalan Sheikh (Arsalan)**.

This repository brings together practical projects developed using modern web technologies. It includes standalone frontend applications, React-based projects, and Next.js applications — each focused on implementing specific functionality, improving development skills, and exploring different aspects of web development.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/arzenjs/arzen-dev-lab.git
```

Navigate into the repository:

```bash
cd arzen-dev-lab
```

Each project is maintained independently and may have its own dependencies and setup instructions.

### Running a Next.js Project

Navigate to the desired project directory:

```bash
cd Mini-Projects/Calculator
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To create a production build:

```bash
npm run build
```

Check the individual project's `package.json` and README for available scripts and additional setup requirements.

### Running the Google Clone

The Google Clone is a standalone HTML, CSS, and JavaScript project.

Navigate to its directory and open `index.html` in your browser:

```bash
cd Mini-Projects/Google
```

No npm installation is required.
